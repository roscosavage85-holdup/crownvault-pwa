# CrownVault

A mobile-first, full-redemption sweepstakes Progressive Web App (PWA) built with React, Node.js/Express, PostgreSQL, and Docker.

## Core Features
- **Dual-Currency Economy:** Separate ledgers for Gold Coins (GC) and Sweeps Coins (SC).
- **Mobile-First PWA:** Installable directly to iOS and Android home screens via `manifest.json` and Service Worker (`sw.js`).
- **Compliance & Security:** Built-in geofencing checks, KYC verification workflows, and PostgreSQL transaction ledgers.
